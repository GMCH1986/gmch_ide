# GMCH IDE 路线图

| 版本 | 主题 | 关键能力 | 出口条件 |
| --- | --- | --- | --- |
| **v0.1.0** | 最小闭环 | 打开工作区、编辑保存、Gradle 编译/运行、输出面板、三平台安装包 | S1–S10 冒烟通过，tag `v0.1.0` |
| v0.2.0 | 可用性 | 多标签、文件树操作（新建/重命名/删除）、错误行跳转、ESLint + Vitest、自动更新 | 日常改代码不需要外部编辑器 |
| v0.3.0 | 智能 | LSP 接入（补全、悬停、跳转、诊断、格式化）、问题面板 | 补全 p95 ≤ 200ms，诊断延迟 ≤ 1s |
| v0.4.0 | 调试 | JDI/调试适配器、断点、变量、调用栈、单步 | 能调试一个 Spring Boot 主类 |
| v0.5.0 | 工程化 | Git 状态与提交、内置终端、多工作区 | 无需切出 IDE 完成提交 |
| v1.0.0 | 分发 | 代码签名 + 公证、增量自动更新、崩溃上报（可选）、主题系统 | 三平台可无警告安装并自动升级 |

## 版本策略

- `0.x` 阶段以「每周一个可验证增量」为节奏，不承诺兼容性；
- 每个版本必须更新 `docs/00-产品需求.md` 的范围表与 `docs/01-技术方案.md` 的已知限制；
- 每个版本发布前执行 `docs/03-发布验证.md` 的冒烟清单。

## 当前阻塞项（v0.1.0）

| 项 | 影响 | 解决方式 |
| --- | --- | --- |
| 本机默认 JDK 为 8 | 无法直接构建后端 | 已在 `.tools/` 放置便携 JDK 21（gitignore），构建时设置 `JAVA_HOME` |
| 当前会话无法启动 Electron 窗口 | S1–S4、S6、S9、S10 未实测 | 在普通桌面机器 / CI 上补测 |
| 无签名证书 | 安装时系统拦截 | v0.2 采购证书；v0.1 在 Release 说明中注明 |
